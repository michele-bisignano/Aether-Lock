# 🧲 Aether-Lock: Sensor Characterization & Measurements

This directory contains the complete analysis ecosystem for characterizing the **SS49E Linear Hall Effect Sensor** used in the Aether-Lock project. The primary goal is to map the sensor's response based on magnet distance and analyze signal stability/noise across various operational conditions.

## 📂 Folder Structure
```
Measurements/
├── Data/
│   ├── Raw/            # Immutable, original Excel recordings
│   └── Processed/      # Merged and cleaned datasets generated by R
├── Scripts/
│   └── analysis.R      # R script
├── Output/             # Final plots and summary reports
├── docs/               # Detailed technical documentation and reports
└── README.md           # This file
```
